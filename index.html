📋 วิธีเชื่อมกับ Google Sheets

ขั้นตอน:

1. อัปโหลด Excel ไป Google Drive → เปิดด้วย Google Sheets

2. ไปที่ Sheet ชื่อ DATA

3. คลิก File → Share → Publish to web

4. เลือก Sheet DATA → Format CSV → กด Publish

5. Copy URL ที่ได้ → วางในช่อง URL ด้านบน

⚠️ ต้องใช้ Publish to web URL (ไม่ใช่ Share link ธรรมดา)

URL จะมีหน้าตาแบบนี้:
https://docs.google.com/spreadsheets/d/.../pub?...output=csv
